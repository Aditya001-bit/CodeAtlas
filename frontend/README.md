# CodeAtlas Frontend

Frontend for the CodeAtlas hackathon MVP.

CodeAtlas helps developers understand a Python codebase through:

- Codebase Map
- Risk View
- Ask Your Codebase

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Flow
- Dagre
- Lucide React

## Run Locally

From the `frontend` folder:

```bash
npm install
npm run dev
